# Questly

App de perguntas anônimas para a turma. A página dos alunos fica em `/` e o painel do professor em `/teacher.html`.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Professor-Andre-Ramiro/questly-server)

Versão de teste: o painel abre sem senha. Para exigir senha, defina a variável `TEACHER_PASSWORD` no Render.
